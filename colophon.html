Colophon

How this site is built, what it publishes, and what it leaves out.

Stack

Static HTML, one CSS file, and a few lines of JavaScript for the image viewer. No framework, no build step, no analytics, no cookies. Hosted on GitHub Pages.

Type

Headings and interface text are set in Bricolage Grotesque. Running text is Source Serif 4. Both are open-source families from Google Fonts, served from this site rather than a third-party host.

What is published

  • Work from published papers, public repositories, course projects, and internship work at the level of detail that already appears on my resume.
  • Screenshots from public demos with sample data only.
  • Aggregate statistics without source imagery for the palm-vein project.

What is left out

  • Biometric images or identifiers.
  • Proprietary datasets, internal identifiers, and anything covered by an NDA.
  • Private account data.

Accessibility

  • Semantic landmarks, a skip link on every page, and keyboard-operable controls with visible focus.
  • Light and dark themes follow the system setting.
  • Reduced-motion preferences are respected.

If something does not work with your setup, email me.
