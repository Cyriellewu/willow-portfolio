Streaming chat engine and telemetry forensics for OfficePLUS AI Assistant

Microsoft, Software Engineer Intern, summer 2026. React, TypeScript, KQL, T-SQL, Azure.

  • Contributed to a React/TypeScript refactor of the assistant's LLM streaming engine, implementing a two-table, session-keyed model with bounded cleanup that cannot evict an active run.
  • Traced backend rate-limit failures across three Azure telemetry stores with KQL and T-SQL. 97.6% were quota exhaustion rather than provider throttling (11,958 vs 295 blocks), which corrected the team's leading hypothesis.
  • Helped raise the assistant's UI success rate from about 70% to 98% by tracing telemetry and fixing double-submit and stall bugs.
  • Fixed a sandbox skill-seed integrity race in a merged PR, refining the check into a randomly sampled two-file probe after performance review and adding reseed telemetry.

Explainable graph neural networks for predictive maintenance

First author, ACML 2025, Proceedings of Machine Learning Research volume 304. Python, PyTorch Geometric, scikit-learn.

  • Reframed a vague "predict failure" request into three supervised tasks linked to maintenance records: emergency-fee existence, cost tier, and subsystem category.
  • Built weighted fault graphs from temporal, spatial, and co-occurrence evidence, with a GCN encoder and Random Forest head, on about 9 million vehicle records.
  • 98.9% fault-category accuracy; high-cost failure precision raised from 60% to 95% under vehicle-wise chronological cross-validation that rules out leakage across vehicles and time.
  • Case study
  • Paper in PMLR

Evidence of Life, a planning and memory app for people with ADHD

Columbia AI Startup Studio, 2026. React 18, TypeScript, Supabase (Postgres, Auth, Edge Functions), Vercel.

  • One low-friction input for plans, dues, habits, and remembered moments, with AI-assisted classification that routes free text into typed records.
  • 30 to 40 early users over about two months. 15 tables with row-level security, 8 Deno edge functions, Vitest and Playwright suites in CI.
  • Traced a Supabase egress exhaustion (402 errors) to a wildcard select that pulled 17 MB of inline photos on every refresh. Listed columns explicitly and added an ESLint rule that blocks wildcard selects in CI.
  • Case study
  • Source on GitHub

Oracle OS, symbolic reflection where code draws the symbols and the model only explains them

Microsoft Global Intern Hackathon 2026, team of three. I built the engines, the app, and the journal loop. TypeScript, Supabase, Vercel.

  • Four rule-based engines (Tarot, I Ching, BaZi, Astrology) generate every symbol in code. LLM calls are isolated to reflection endpoints and never choose the symbols.
  • Medical, legal, and financial prompts are redirected. Prompts are externalized and API inputs validated, so the boundary between code and model is inspectable.
  • A journal loop extracts recurring motifs and personalizes the next day's prompt. A mock-LLM fallback keeps the demo working without API keys.
  • Case study
  • Source on GitHub
