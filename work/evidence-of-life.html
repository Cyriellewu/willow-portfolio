Evidence of Life

A planning and memory app for people with ADHD. One low-friction input takes plans, dues, habits, and remembered moments, and AI-assisted classification routes each one into a typed record with calendar and place context.

Problem

For someone with ADHD, writing a plan down can itself become the task that gets dropped. The product's bet is that capture has to be nearly free: one box, free text or voice, and the app decides where it goes.

What I built

A React and TypeScript single-page app on Supabase, deployed on Vercel. The data model has 15 tables with row-level security on every one, 63 owner policies, and a private storage bucket for photos served through one-hour signed URLs.

  • Smart input: an edge function sends the text to a model with three tools, classify, query, and modify, keeps six turns of history, maps rate-limit and quota errors to user-facing messages, and falls back to plain text.
  • Calendar sync and map memory, so a moment can be revisited by when and where it happened.
  • Security: JWT checks in every edge function, HMAC-signed OAuth state with expiry and nonce, a redirect-origin allowlist, an SSRF guard on link previews, and only the publishable key in the browser.
  • Tests: Vitest suites, Playwright smoke tests, and Deno auth tests that run in CI.

A bug worth describing

The Supabase free plan ran out of egress and the app started returning 402 errors. The cause was one wildcard select that pulled about 17 MB of inline photos on every refresh. I listed the columns explicitly, moved photos to signed URLs with an in-memory cache and in-flight dedupe, and added an ESLint rule that blocks wildcard selects in CI so it cannot come back.

Limits

The app makes no clinical claim. The screenshot here is the public demo with sample data; no real account, journal, map, or connected calendar is shown. Account deletion and a live RLS audit are still on the roadmap.
